## Boundaries and remaining acceptance

Navigation abandons ephemeral jobs/reviews and discards stale outcomes. Hiding preserves admitted work
and explicit background services; independent schedulers/recorders do not rely on visible UI frames.
Stop/Quit close admission, cancel owned work, join workers/children and restore session-owned leases.
Persisted configuration uses bounded atomic storage and rollback; secrets and active-session restoration
are excluded from presets. Operations already admitted to an OS or intentionally external application
cannot always be revoked, and external filesystem/window/registry changes leave a final check/use race.

This record does not certify live power/window/radio/startup/registry/uninstall/Trash/shred behavior,
actual camera/microphone/capture/clipboard contents, provider quality/codecs, screen-reader/keyboard/IME/
DPI behavior, all-OS runtime privacy or independent human security/license review. User-installed
FFmpeg/Tesseract remain optional and unbundled. File overwrite does not guarantee SSD/CoW/snapshot/
backup sanitization. The manual ECB exception remains explicitly opt-in; native rendering or bounded
endpoint observations are not a universal zero-network proof.

**Clean-machine install/login/upgrade/uninstall remains pending by explicit user instruction. The
release must remain an unpublished draft/prerelease.** Final source, CI, packaging, GUI and privacy
evidence belong with [validation](../VALIDATION.md), [release gates](../RELEASE.md) and
[native migration acceptance](../../tasks/native-migration.md), without checking unsupported manual
gates on the strength of source/headless tests.
