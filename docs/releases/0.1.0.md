# Oxbox 0.1.0 — Windows draft prerelease

This draft contains Windows x64 MSI and NSIS installers for the 48-tool catalogue, including the
user-promoted Phase 5 tools. It is prepared for review and testing; public release acceptance is still open.

The app includes local file utilities, text/time/conversion tools, system and window controls, capture and
media tools, and opt-in currency reference rates. See the [changelog](../../CHANGELOG.md),
[usage guide](../USAGE.md) and [platform/provider notes](../ROADMAP_TOOLS.md).

## Installation and integrity

- Windows 10/11 x64 and Microsoft WebView2 are required. Installer setup can download Microsoft's WebView2
  bootstrapper/runtime when it is missing; that installation prerequisite is separate from app runtime behavior.
- The installers are unsigned. Signing and an automatic updater are not configured.
- `SHA256SUMS.txt` accompanies the two installers. Compare a downloaded asset with
  `Get-FileHash -Algorithm SHA256 PATH_TO_INSTALLER` before testing it.
- The installers include the project's MIT/Apache-2.0 licenses and a generated third-party notice inventory.
- FFmpeg and Tesseract are optional user-installed local providers; their binaries are not included.

## Runtime behavior

Oxbox implements no app telemetry. Tool commands are local by default. Currency refresh is disabled unless separately opted in
and manually requested; it fetches only the fixed ECB public feed approved in
[issue #1](https://github.com/ninad-k/oxbox/issues/1). Amounts, selected currencies, clipboard contents,
passphrases and recordings are not uploaded by Oxbox commands. Clipboard history starts paused and stays in memory.

**Known runtime privacy gap:** Windows QA observed the embedded WebView2 browser process maintaining HTTPS
to a public Microsoft address without a currency refresh. Its exact request purpose was not identified.
Strict whole-process offline acceptance has not passed. See the [observations and SDK privacy scope](../RUNTIME_PRIVACY.md);
this draft must not be presented as a zero-network runtime release.

## Validation and remaining gates

The [validation record](../VALIDATION.md) contains the exact local check results and native smoke evidence.
The draft's target commit and linked GitHub Actions run identify the source used for these assets.

Before public publication, complete clean-machine install/uninstall and startup checks, the full Windows
hardware/power/destructive-action matrix in a consenting test account or VM, multi-monitor/DPI checks,
independent human security and license review, default-offline runtime observation, and supported-tool
runtime acceptance on macOS and Linux. No physical microphone/camera recording, power change, live cleanup,
uninstall or removable-drive effect is represented as tested by fixture-based automated checks.
7z uses a conservative compression profile and a 128 KiB stored/decoded metadata limit; some legitimate
archives outside that policy are refused. Decoder/model budgets are not process-wide memory ceilings;
see [ADR 0003](../adr/0003-bounded-7z.md).

Dependency scans and their limits are recorded in [dependency notes](../DEPENDENCIES.md). Upstream
maintenance warnings and the Linux-only GLib binding advisory remain tracked; Windows draft assets do not
establish Linux security or runtime acceptance. Keep this draft unpublished while acceptance gates remain open.
