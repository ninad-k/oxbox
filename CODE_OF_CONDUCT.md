# Oxbox community code of conduct

Oxbox welcomes contributors of all backgrounds and experience levels. Be respectful, explain your reasoning,
and help others learn. Critique code and ideas without attacking people. Respect privacy and credit original work.

Harassment, discrimination, threats, sexualized attention, publishing private information, and repeated disruption
are not acceptable in issues, pull requests, discussions, or other project spaces. Maintainers may edit or remove
content, close discussions, or restrict participation when necessary. They should explain moderation decisions
privately when practical and apply these standards consistently, including to themselves.

For abuse involving a GitHub account, use GitHub's private **Report abuse** action. Do not post private reports
or identifying details in a public issue. For a software vulnerability, follow [SECURITY.md](SECURITY.md).

Participation in the project means following these standards. Maintainers and contributors share responsibility
for making the project constructive and welcoming.
